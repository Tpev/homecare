# Homepage press logos

Publisher assets retrieved on 2026-10-01 for the confirmed LoLo Care press placements.
Logos are served locally and displayed in grayscale by the homepage stylesheet.

- `yahoo-news.svg`: inline Yahoo News masthead SVG from https://news.yahoo.com/. Publisher-specific CSS classes replaced with explicit monochrome fills so the standalone image renders correctly.
- `associated-press.svg`: AP logo symbol from https://www.ap.org/, exported as a standalone SVG with its original geometry and colors.
- `markets-insider.svg`: https://markets.businessinsider.com/Content/dist/images/markets-insider-logo.svg
- `north-carolina-daily.png`: https://assets.kreatio.net/pr_logos/north-carolina-daily.png, as used in the masthead at https://www.northcarolinadaily.com/.

Publisher names and marks belong to their respective owners. The row identifies press appearances; it does not state an endorsement.
