# Care Assistance photography

User-supplied Pexels photographs, added for the Care Assistance landing page.

- `community-support-*`: `pexels-rdne-6647126.jpg` (6368 x 4245), hero and social preview.
- `helping-hand-at-home-*`: `pexels-jsme-mila-523821574-29372727.jpg` (5805 x 3870), supporting section.

WebP variants are resized to 640, 960, and 1440 pixels wide at quality 82 with metadata stripped. The social preview is a progressive JPEG at 1200 pixels wide, quality 86. All assets retain the source composition; responsive framing is controlled by the page CSS.
